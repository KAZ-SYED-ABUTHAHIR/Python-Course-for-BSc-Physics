பைதான் அடிப்படைகள்: தரவு வகைகள்

மாறிகள், தரவு வகைகள் மற்றும் தரவு வகை மாற்றங்கள் குறித்த தெளிவான குறிப்புகள்

அஞ்சறைப் பெட்டி மற்றும் மாறிகள் (Variables & Anjarai Petti)

பைதான் நிரலாக்கத்தில் தரவுகளை சேமிக்க மாறிகள் (Variables) பயன்படுகின்றன. இதை நம் வீடுகளில் உள்ள அஞ்சறைப் பெட்டியுடன் (Spice Box) ஒப்பிடலாம்.

அஞ்சறைப் பெட்டியில் கடுகு, சீரகம், மிளகு, வெந்தயம் என வெவ்வேறு மசாலாப் பொருட்களை வெவ்வேறு சிறிய கிண்ணங்களில் பாதுகாப்பாக சேமித்து வைப்பது போல, பைத்தானில் நாம் எழுத்துக்கள், எண்கள், மற்றும் இதர தரவுகளை கணினியின் நினைவகத்தில் சேமிக்க மாறிகளைப் பயன்படுத்துகிறோம். நாம் எப்படி மசாலாப் பொருட்களின் தன்மையைப் பொறுத்து வெவ்வேறு கிண்ணங்களைத் தேர்ந்தெடுக்கிறோமோ, அதே போல பைத்தானில் வெவ்வேறு வகையான தகவல்களைச் சேமிக்க வெவ்வேறு தரவு வகைகள் (Data Types) உள்ளன.

அடிப்படை தரவு வகைகள் (Primitive Data Types)

பைத்தானில் முக்கியமாக நான்கு அடிப்படை தரவு வகைகள் உள்ளன:

1. String (சரம் - str)

எழுத்துக்கள் அல்லது வாக்கியங்களை குறிக்கிறது. இவற்றை ஒற்றை (' ') அல்லது இரட்டை மேற்கோள் (" ") குறிகளுக்குள் கொடுக்க வேண்டும்.

name = "தமிழ்"
spice = 'கடுகு'

2. Integer (முழு எண் - int)

தசம புள்ளி (Decimal point) இல்லாத நேர்மறை அல்லது எதிர்மறை முழு எண்களைக் குறிக்கிறது.

age = 25
count = -5

3. Float (தசம எண் - float)

தசம புள்ளி (Decimal point) கொண்ட எண்களைக் குறிக்கிறது. அளவுகள், எடைகள் போன்றவற்றைக் குறிக்கப் பயன்படுகிறது.

height = 5.8
weight = 65.5

4. Boolean (பூலியன் - bool)

இது இரண்டு மதிப்புகளை மட்டுமே கொண்டிருக்கும்: சரி (True) அல்லது தவறு (False).

is_educated = True
is_valid = False

type() சார்பு: தரவு வகையை கண்டறிதல்

ஒரு மாறி அல்லது மதிப்பு எந்த தரவு வகையைச் சேர்ந்தது என்பதை அறிய பைத்தானில் type() என்ற சார்பு (function) பயன்படுகிறது.

item = "சீரகம்" print(type(item)) # வெளியீடு: <class 'str'> weight = 50.5 print(type(weight)) # வெளியீடு: <class 'float'>

input() சார்பு: பயனரிடமிருந்து உள்ளீடு பெறுதல்

நிரல் இயங்கும் போது பயனரிடமிருந்து தகவல்களைப் பெற input() பயன்படுகிறது.

முக்கிய குறிப்பு: input() மூலம் பெறப்படும் தரவு எப்போதும் சரமாக (String - str) மட்டுமே இருக்கும். நீங்கள் எண்களை உள்ளீடு செய்தாலும், அது எழுத்தாகவே சேமிக்கப்படும்.
user_name = input("உங்கள் பெயரை உள்ளிடவும்: ") print("வணக்கம்", user_name)

தரவு வகை மாற்றம் (Type Conversion / Casting)

ஒரு தரவு வகையிலிருந்து மற்றொரு தரவு வகைக்கு மாற்றுவது Type Conversion எனப்படுகிறது. `input()` மூலம் பெறப்படும் மதிப்பை எண்களாக மாற்ற இது மிகவும் அவசியமாகிறது.

முக்கியமான மாற்றுச் சார்புகள்:

  • int() - மற்ற வகைகளை முழு எண்ணாக மாற்றும்.
  • float() - மற்ற வகைகளை தசம எண்ணாக மாற்றும்.
  • str() - மற்ற வகைகளை சரமாக மாற்றும்.
  • bool() - மற்ற வகைகளை பூலியனாக மாற்றும்.
# String-ஐ Integer-ஆக மாற்றுதல் string_num = "10" int_num = int(string_num) # இப்போது இது 10 (int) ஆகிவிட்டது # input() உடன் Type Conversion பயன்படுத்துதல் age_input = input("உங்கள் வயதை உள்ளிடவும்: ") # இது String ஆக வரும் actual_age = int(age_input) # String இப்போது Integer ஆக மாறிவிட்டது # இதை ஒரே வரியிலும் எழுதலாம்: weight_kg = float(input("உங்கள் எடையை உள்ளிடவும் (கிலோவில்): ")) # Integer-ஐ String-ஆக மாற்றுதல் year_value = 2023 sentence = "ஆண்டு: " + str(year_value) # எண்களை எழுத்துக்களுடன் இணைக்க str() பயன்படுகிறது
